# Talk With Dr. Jaavi

A counseling and psychotherapy practice website — built around the brand identity in the Logo Presentation Sheet.

**Live site:** https://drjaavi.example/ *(replace once GitHub Pages is live)*

## Stack

Static site — no build step.

- `index.html` — single-page site
- `styles.css` — Lora + JetBrains Mono, plum/cream brand palette
- `script.js` — scroll reveals, magnetic buttons, parallax, mobile nav
- `assets/` — logos (SVG/PNG/JPG) and stock imagery

## Local preview

Just open `index.html` in a browser, or serve the folder:

```sh
python -m http.server 8080
# then visit http://localhost:8080
```
